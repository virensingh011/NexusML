Model Limitations

Independent variables assumed. In reality, climate vulnerability correlates with infrastructure quality and response capacity — a region with high vulnerability rarely maintains top-tier infrastructure. Emergency response times below 3 minutes are theoretical. The model extrapolates with decreasing confidence beyond observed global data. Linear weighting simplifies complex interactions. Real disaster risk involves non-linear thresholds, cascading failures, and feedback loops not captured here. Anomaly detection uses static centroids. Normal ranges shift over time with development and climate change; the model does not adapt dynamically.

For real deployment: calibrate weights against historical disaster data, add correlated feature constraints, and update normal baselines annually. This prototype demonstrates system architecture, not production readiness.
